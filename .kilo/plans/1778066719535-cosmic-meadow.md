# Technical Implementation Plan: Real-Time Data Synchronization Architecture

## Project Overview
**Application:** CareVault - Flutter mobile application for managing medications, follow-ups, and vital signs
**Current Architecture:** Traditional pull-on-load with Riverpod state management and SQLite local database
**Issue:** Data entries (medicines, follow-ups, vital signs) require manual app restart to reflect updates across UI screens
**Goal:** Implement seamless reactive/real-time data synchronization architecture

## 1. Root Cause Analysis

### Current Architecture Limitations
The application currently uses a **pull-on-load** pattern with these characteristics:

1. **Database-First Flow:** Each provider (Medicine, FollowUp, VitalSign) loads data only on initialization (`_loadMedicines()`, `_loadFollowUps()`, etc.)
2. **Manual Refresh Required:** UI screens require explicit refresh calls (`refresh()` method) or provider invalidation
3. **No Event Propagation:** Database changes don't trigger automatic UI updates across different screens
4. **Provider Isolation:** Each provider operates independently with no cross-provider synchronization
5. **Dashboard Data Staleness:** Dashboard shows cached `AsyncValue` states that don't update when underlying data changes

### Why Latency Occurs in RESTful vs Reactive Patterns
- **RESTful (Current):** Client must poll/request data; server has no mechanism to push updates
- **Reactive (Target):** Server/client maintains persistent connection for real-time updates
- **State Management Gap:** Current Riverpod providers don't listen to database changes

## 2. Proposed Architectural Solutions

### Option 1: Event-Driven State Management with Database Observers (RECOMMENDED)
**Approach:** Implement a database change notification system using `Stream` pattern
- **Technology:** Custom `StreamController` + Database trigger mechanism
- **Pros:** Lightweight, works offline, no external dependencies, aligns with current architecture
- **Cons:** Requires careful memory management, manual stream disposal

### Option 2: WebSockets for Bidirectional Communication
**Approach:** Add WebSocket server for real-time push notifications
- **Technology:** `web_socket_channel` package
- **Pros:** True real-time, supports multiple clients, standardized protocol
- **Cons:** Requires backend infrastructure, complex offline handling, overkill for local-first app

### Option 3: Server-Sent Events (SSE)
**Approach:** One-way server-to-client event stream
- **Technology:** HTTP streaming with `sse` package
- **Pros:** Simpler than WebSockets, works with existing HTTP infrastructure
- **Cons:** One-way only, still requires backend, not suitable for pure local app

### Option 4: Reactive Database with Change Listeners
**Approach:** Use database-native change notifications
- **Technology:** SQLite triggers + `ChangeNotifier` pattern
- **Pros:** Database-level awareness, minimal code changes
- **Cons:** SQLite has limited built-in notification support

### Recommendation: Riverpod-Integrated Event System (Custom Solution)
Based on the existing Riverpod architecture, implement a **Riverpod-native event system**:

1. **Riverpod State Notifier Enhancement:** Extend existing notifiers with event listening capabilities
2. **Database Change Observer:** Lightweight SQLite polling with `last_modified` timestamps
3. **Provider-to-Provider Communication:** Use Riverpod's `ref.listen` for cross-provider updates
4. **Optimistic Updates:** Immediate state changes with async validation

**Why this approach works best for CareVault:**
- **Minimal dependencies:** No new packages needed
- **Riverpod-native:** Leverages existing state management patterns
- **Incremental adoption:** Can update one provider at a time
- **Memory safe:** Built-in Riverpod lifecycle management

   ```dart
     final optimisticMedicine = medicine.copyWith(id: 'temp_${DateTime.now().millisecondsSinceEpoch}');
     state = state.copyWith(medicines: [...state.medicines, optimisticMedicine]);
     
     // 2. Perform actual database operation
     try {
       final actualId = await _medicineRepository.createMedicine(medicine);
       
       // 3. Replace optimistic entry with actual data
       final updatedList = state.medicines.map((m) => 
         m.id == optimisticMedicine.id ? medicine.copyWith(id: actualId) : m
       ).toList();
       
       state = state.copyWith(medicines: updatedList);
     } catch (e) {
       // 4. Rollback on error
       final rolledBackList = state.medicines.where((m) => m.id != optimisticMedicine.id).toList();
       state = state.copyWith(medicines: rolledBackList, error: e.toString());
       rethrow;
     }
   }
   ```

```dart
class ReactiveMedicineNotifier extends MedicineListNotifier {
  StreamSubscription? _changeSubscription;
  
  ReactiveMedicineNotifier(MedicineRepository medicineRepository, ReminderScheduler reminderScheduler)
      : super(medicineRepository, reminderScheduler) {
    // Initial load
    _loadMedicines();
    
    // Listen for database changes
    _setupChangeListener();
  }
  
  void _setupChangeListener() {
    // Listen to database change monitor
    _changeSubscription = ref.listen<DatabaseChangeState>(
      databaseChangeMonitorProvider,
      (previous, next) {
        if (next.hasChangesForTable('medicines')) {
          _handleMedicineChanges(next.getChangesForTable('medicines'));
        }
      },
    );
  }
  
  void _handleMedicineChanges(List<DatabaseChange> changes) {
    // Batch update medicines based on change types
    final updatedMedicines = List<Medicine>.from(state.medicines);
    
    for (final change in changes) {
      switch (change.operation) {
        case 'INSERT':
          final newMedicine = await _medicineRepository.getMedicineById(change.rowId);
          if (newMedicine != null) {
            updatedMedicines.add(newMedicine);
          }
          break;
        case 'UPDATE':
          final updatedMedicine = await _medicineRepository.getMedicineById(change.rowId);
          if (updatedMedicine != null) {
            final index = updatedMedicines.indexWhere((m) => m.id == change.rowId);
            if (index != -1) {
              updatedMedicines[index] = updatedMedicine;
            }
          }
          break;
        case 'DELETE':
          updatedMedicines.removeWhere((m) => m.id == change.rowId);
          break;
      }
    }
    
    state = state.copyWith(medicines: updatedMedicines);
  }
  
  @override
  void dispose() {
    _changeSubscription?.cancel();
    super.dispose();
  }
}
```

```dart
class ReactiveFollowUpNotifier extends FollowUpListNotifier {
  // Listen to both follow-up and medicine changes
  StreamSubscription? _followUpSubscription;
  StreamSubscription? _medicineSubscription;
  
  @override
  void _setupChangeListeners() {
    _followUpSubscription = ref.listen<DatabaseChangeState>(
      databaseChangeMonitorProvider,
      (previous, next) {
        if (next.hasChangesForTable('follow_ups')) {
          _handleFollowUpChanges(next.getChangesForTable('follow_ups'));
        }
      },
    );
    
    // Also listen to medicine changes since follow-ups reference medicines
    _medicineSubscription = ref.listen<DatabaseChangeState>(
      databaseChangeMonitorProvider,
      (previous, next) {
        if (next.hasChangesForTable('medicines')) {
          // If a referenced medicine is deleted, update follow-up list
          _refreshFollowUpsWithMedicineChanges(next.getChangesForTable('medicines'));
        }
      },
    );
  }
}

// New provider for cross-entity synchronization
```

```dart
class ReactiveVitalSignNotifier extends VitalSignListNotifier {
  // Real-time chart data stream
  final _chartDataController = StreamController<List<VitalSign>>.broadcast();
  Stream<List<VitalSign>> get chartDataStream => _chartDataController.stream;
  
  @override
  void _handleVitalSignChanges(List<DatabaseChange> changes) {
    super._handleVitalSignChanges(changes);
    
    // Update chart stream
    _chartDataController.add(state.vitalSigns);
    
    // Check for threshold alerts
    _checkThresholdAlerts(changes);
  }
  
  void _checkThresholdAlerts(List<DatabaseChange> changes) {
    for (final change in changes) {
      if (change.operation == 'INSERT' || change.operation == 'UPDATE') {
        final vitalSign = await _vitalSignRepository.getVitalSignById(change.rowId);
        if (vitalSign != null && _isAbnormalReading(vitalSign)) {
          // Trigger alert notification
          _emitAlertNotification(vitalSign);
        }
      }
    }
  }
}
```

## 4. Data Integrity & Edge Cases

### Synchronization During Intermittent Connectivity
**Strategy:** Operation Queue + Retry Mechanism
1. **Local First:** Always update local database immediately
2. **Queue Operations:** Store pending sync operations
3. **Exponential Backoff:** Retry failed operations with increasing delays
4. **Conflict Resolution:** Last-write-wins or manual resolution based on data type

### Race Conditions
**Prevention:** Transaction Isolation + Event Sequencing
1. **Database Transactions:** Ensure atomic operations
2. **Event Sequencing:** Maintain operation order
3. **Optimistic Locking:** Version stamps for concurrent edits
4. **Conflict Detection:** Compare timestamps and versions

### Multi-Device Consistency
**Approach:** Event Sourcing + CQRS Pattern
1. **Event Sourcing:** Store all changes as immutable events
2. **CQRS:** Separate read/write models
3. **Event Replay:** Rebuild state from event history
4. **Device Sync:** Periodic synchronization between devices

### Data Consistency Guarantees
1. **Strong Consistency:** Within same screen/session
2. **Eventual Consistency:** Across screens/devices
3. **Conflict Resolution Policies:**
   - Medicines: Last prescription wins
   - Vital Signs: Keep all readings, flag duplicates
   - Follow-ups: Manual merge required

```dart
// Riverpod provider for database change monitoring
final databaseChangeMonitorProvider = StateNotifierProvider<DatabaseChangeNotifier, DatabaseChangeState>((ref) {
  final databaseHelper = ref.watch(databaseHelperProvider);
  return DatabaseChangeNotifier(databaseHelper);

class DatabaseChangeState {
  final Map<String, List<DatabaseChange>> changesByTable;
  final DateTime lastCheck;
  final bool isMonitoring;
  
  bool hasChangesForTable(String tableName) => 
    changesByTable[tableName]?.isNotEmpty ?? false;
  
  List<DatabaseChange> getChangesForTable(String tableName) => 
    changesByTable[tableName] ?? [];
}

class DatabaseChangeNotifier extends StateNotifier<DatabaseChangeState> {
  final DatabaseHelper _databaseHelper;
  Timer? _pollingTimer;
  
  DatabaseChangeNotifier(this._databaseHelper)
      : super(DatabaseChangeState(
          changesByTable: {},
          lastCheck: DateTime.now(),
          isMonitoring: false,
        )) {
    _startMonitoring();
  }
  
  Future<void> _startMonitoring() async {
    state = state.copyWith(isMonitoring: true);
    
    // Poll every 2 seconds (configurable)
    _pollingTimer = Timer.periodic(Duration(seconds: 2), (_) {
      _checkForChanges();
    });
  }
  
  Future<void> _checkForChanges() async {
    try {
      final changes = await _databaseHelper.getChangesSince(state.lastCheck);
      final changesByTable = _groupChangesByTable(changes);
      
      if (changes.isNotEmpty) {
        state = state.copyWith(
          changesByTable: changesByTable,
          lastCheck: DateTime.now(),
        );
        
        // Clear changes after processing (or keep for history)
        await _markChangesAsProcessed(changes);
      }
    } catch (e) {
      // Log error but don't crash
      ErrorUtils.logError('Database change monitoring failed', error: e);
    }
  }
  
  Map<String, List<DatabaseChange>> _groupChangesByTable(List<DatabaseChange> changes) {
    final Map<String, List<DatabaseChange>> result = {};
    
    for (final change in changes) {
      result.putIfAbsent(change.tableName, () => []).add(change);
    }
    
    return result;
  }
  
  @override
  void dispose() {
    _pollingTimer?.cancel();
    super.dispose();
  }
}
```

```dart
class MedicineRepositoryImpl implements MedicineRepository {
  final MedicineDataSource _medicineDataSource;
  final DatabaseHelper _databaseHelper;
  
  @override
  Future<String> createMedicine(Medicine medicine) async {
    // Set timestamps
    final now = DateTime.now().millisecondsSinceEpoch;
    final medicineWithTimestamps = medicine.copyWith(
      lastModified: now,
      version: 1,
    );
    
    // Perform database operation
    final id = await _medicineDataSource.createMedicine(medicineWithTimestamps);
    
    // Record change in audit table
    await _databaseHelper.recordChange(
      tableName: 'medicines',
      rowId: id,
      operation: 'INSERT',
      timestamp: now,
    );
    
    return id;
  }
  
  @override
  Future<int> updateMedicine(Medicine medicine) async {
    // Optimistic locking check
    final current = await getMedicineById(medicine.id);
    if (current != null && current.version != medicine.version) {
      throw ConcurrentModificationException(
        'Medicine was modified by another process',
        currentVersion: current.version,
        attemptedVersion: medicine.version,
      );
    }
    
    // Update with new version and timestamp
    final now = DateTime.now().millisecondsSinceEpoch;
    final updatedMedicine = medicine.copyWith(
      lastModified: now,
      version: (medicine.version ?? 1) + 1,
    );
    
    final result = await _medicineDataSource.updateMedicine(updatedMedicine);
    
    // Record change
    await _databaseHelper.recordChange(
      tableName: 'medicines',
      rowId: medicine.id,
      operation: 'UPDATE',
      timestamp: now,
    );
    
    return result;
  }
}
```

### DatabaseHelper Extensions
```dart
extension DatabaseChangeTracking on DatabaseHelper {
  Future<List<DatabaseChange>> getChangesSince(DateTime since) async {
    final db = await database;
    final timestamp = since.millisecondsSinceEpoch;
    
    return await db.query(
      'database_changes',
      where: 'timestamp > ? AND sync_status != ?',
      whereArgs: [timestamp, 'processed'],
      orderBy: 'timestamp ASC',
    ).then((rows) => rows.map(DatabaseChange.fromMap).toList());
  }
  
  Future<void> recordChange({
    required String tableName,
    required String rowId,
    required String operation,
    required int timestamp,
  }) async {
    final db = await database;
    
    await db.insert('database_changes', {
      'table_name': tableName,
      'row_id': rowId,
      'operation': operation,
      'timestamp': timestamp,
      'sync_status': 'pending',
    });
  }
  
  Future<void> markChangesAsProcessed(List<String> changeIds) async {
    final db = await database;
    
    await db.update(
      'database_changes',
      {'sync_status': 'processed'},
      where: 'id IN (${List.filled(changeIds.length, '?').join(',')})',
      whereArgs: changeIds,
    );
  }
}
```
